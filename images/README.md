# Папка для фотографий сайта

Рабочие изображения лендинга сейчас лежат в соседней папке **`public/repetitor_landing_images/`**
(пути к ним заданы в `src/data/data.ts`). Сюда удобно класть собственные фото.

Как заменить, например, фото преподавателя:

1. Положите файл сюда, например `public/images/teacher.jpg` (рекомендация: горизонтальный
   кадр или 4:3, до ~300 КБ — для сжатия удобен squoosh.app).
2. В `src/data/data.ts` укажите путь:

   ```ts
   export const teacher = {
     photo: 'images/teacher.jpg',
     ...
   }
   ```

   Если поле оставить пустым (`''`) — секция покажет встроенную SVG-заглушку.

Аналогично меняются картинка первого экрана (`hero.photo`), иллюстрации предметов
(`subjects.items[*].art`) и секции «Как проходят занятия» (`process.image`).
