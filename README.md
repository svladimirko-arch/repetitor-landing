# Лендинг для онлайн-репетитора по математике и физике

Современный адаптивный одностраничный сайт (демо-шаблон) для частного репетитора.
Стек: **React 18 + TypeScript + Vite**, без UI-библиотек — чистые компоненты и CSS.

## Быстрый старт

```bash
npm install      # один раз
npm run dev      # запуск для разработки → http://localhost:5173
npm run build    # продакшен-сборка в dist/
npm run preview  # локальный просмотр собранной версии
```

## Где что менять (персонализация под репетитора)

### 1. Все тексты, цены, контакты — в одном файле

**`src/data/data.ts`** — единый конфигурационный файл сайта. В нём меняются:

| Что                              | Переменная в data.ts          |
| -------------------------------- | ----------------------------- |
| Название бренда в шапке/подвале  | `site.brand`, `site.tagline`  |
| SEO-заголовок и описание         | `site.meta.title`, `site.meta.description` |
| Имя преподавателя, текст «О себе», показатели | `teacher`        |
| Первый экран (заголовок, кнопки) | `hero`                        |
| Секция задач (4 карточки)        | `tasks`                       |
| Предметы и их списки             | `subjects`                    |
| Классы 1–4 / 5–8 / 9–11          | `audiences`                   |
| Преимущества                     | `advantages`                  |
| Шаги «как проходят занятия»      | `process`                     |
| Отзывы (демо-заглушки)           | `reviews.items`               |
| Тарифы и цены `[Цена]`           | `pricing.plans`               |
| Вопросы FAQ                      | `faq.items`                   |
| Тексты формы заявки              | `cta`                         |
| Телефон, Telegram, WhatsApp, VK  | `contacts` (демо-значения!)   |
| Текст политики конфиденциальности| `privacy`                     |

Меню навигации: `nav`. Новые отзывы добавляются копированием объекта в `reviews.items`.

### 2. Изображения

Картинки сайта лежат в **`public/repetitor_landing_images/`** и подключаются через пути в data.ts:

| Картинка | Файл | Где используется |
| --- | --- | --- |
| Иллюстрация первого экрана (футуристический стол) | `01_glavnaya_illyustratsiya_futurist.jpg` | `hero.photo` |
| Фото преподавателя (заглушка, мужчина) | `02_foto_prepodavatelya_muzhchina.svg` | `teacher.photo` |
| Математика | `03_matematika.png` | `subjects.items[0].art` |
| Физика | `04_fizika.png` | `subjects.items[1].art` |
| Онлайн-обучение | `05_onlayn_obuchenie.png` | `process.image` |
| Декоративный фон | `06_dekorativnyy_fon.png` | `cta.backgroundImage` |

Чтобы заменить картинку: положите свой файл в `public/` (например `public/images/teacher.jpg`)
и укажите путь в data.ts — либо просто замените файл в `repetitor_landing_images/`, сохранив имя.
Если поле в data.ts оставить пустым (`''`), секция показывает встроенную SVG-иллюстрацию.

Все изображения выводятся в естественных пропорциях (`width: 100%; height: auto`),
без растяжения; фон CTA-блока — через `object-fit: cover` (обрезка без искажения).
Изображения ниже первого экрана загружаются лениво (`loading="lazy"`).

### 3. Цвета и шрифты

**`src/styles/global.css`** — блок `:root`: палитра (синий/бирюза/янтарный акцент),
скругления, тени, шрифты (Manrope + JetBrains Mono через Google Fonts).

### 4. Favicon

**`public/favicon.svg`** — атом в фирменных цветах.

## Структура проекта

```
src/
  data/data.ts               ← ВСЕ ДАННЫЕ САЙТА (менять здесь)
  styles/global.css          ← дизайн-токены, база, кнопки, анимации
  lib/scroll.ts              ← плавный скролл с учётом reduced-motion
  components/
    Header.tsx/.css          ← фиксированное меню + мобильный бургер + подсветка раздела
    Hero.tsx/.css            ← блок 1: первый экран
    Tasks.tsx/.css           ← блок 2: с какими задачами помогу
    Subjects.tsx/.css        ← блок 3: направления (математика/физика)
    Audiences.tsx/.css       ← блок 4: для кого занятия (1–4, 5–8, 9–11)
    Advantages.tsx/.css      ← блок 5: преимущества
    About.tsx/.css           ← блок 6: о преподавателе (+ фото-заглушка)
    Process.tsx/.css         ← блок 7: как проходят занятия (4 шага)
    Reviews.tsx/.css         ← блок 8: отзывы (с меткой «Демо»)
    Pricing.tsx/.css         ← блок 9: тарифы
    Faq.tsx/.css             ← блок 10: аккордеон вопросов
    Cta.tsx/.css             ← блок 11: форма заявки (демо-обработка)
    Footer.tsx/.css          ← блок 12: контакты, подвал, модалка политики
    ui/Icon.tsx              ← набор SVG-иконок (добавление — в словарь glyphs)
    ui/Reveal.tsx            ← появление блоков при прокрутке
    ui/SectionHead.tsx       ← заголовки секций
    illustrations/           ← тематические SVG-иллюстрации
```

## Особенности реализации

- **Адаптивность**: брейкпоинты 1023 / 960 / 900 / 560 / 480 px; мобильное меню, полноразмерные кнопки.
- **Анимации**: появление секций при прокрутке (IntersectionObserver), плавающие декоративные элементы,
  «отрисовка» графиков в SVG, каскадное появление карточек. Полная поддержка `prefers-reduced-motion`.
- **Форма заявки** — демонстрационная: валидация полей, экран успешной отправки,
  данные выводятся в консоль браузера и никуда не отправляются. Для подключения реальной отправки
  правится функция `onSubmit` в `src/components/Cta.tsx`.
- **Отзывы** помечены бейджем «Демо» и подписью, что будут заменены реальными.
- **Цены** — заполнители `[Цена]`, реальные значения задаются в data.ts.
- **SEO**: `title`, `description`, OG-теги, иерархия H1–H3, alt у изображений, `lang="ru"`.
- Кнопки предметов подставляют предмет в форму, кнопки тарифов — предзаполняют комментарий.
